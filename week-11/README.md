# Week 11 — Random Forests

**DATA 201: Statistical Methods in Data Science**  
**Instructor:** Rebin Muhammad, Montgomery College

## Topics

- **From one tree to a forest** — Why averaging many different trees reduces variance.
- **Random forests** — Bootstrap rows plus a random feature subset at each split.
- **Tuning** — `n_estimators`, `max_features`, `max_depth`.
- **Interpretation** — Feature importances (what the forest used, not causation).
- **Boosting (preview)** — Sequential trees that correct previous mistakes.
